以东京节点的公开检测为例：IP 段属于 IT7 / Fiber Logic（AS21887 / AS25820）的 IDC 广播 IP。Scamalytics 和 ipapi 判定为低风险，IPQS 给出 75 分并标记为“suspicious”。流媒体解锁整体可用性不错，但它是机房 IP，对 IP 纯净度要求高的用途（比如注册对 IP 类型敏感的平台账号）要有合理预期，别按住宅 IP 的标准来衡量它。
